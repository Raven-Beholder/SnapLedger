# SnapLedger

SnapLedger is a SwiftUI ledger app for importing, recognizing, organizing, and reviewing transactions.

## Requirements

- A recent version of Xcode compatible with the project's deployment targets
- macOS or iOS simulator/device supported by the active Xcode scheme

## Build and run

1. Clone this repository.
2. Open `SnapLedger.xcodeproj` in Xcode.
3. Select the `SnapLedger` scheme and a compatible run destination.
4. Press **Run** (`Command-R`).

No third-party dependencies or additional setup are required.

## Tests

Select the `SnapLedger` scheme and press **Test** (`Command-U`).

See [ARCHITECTURE.md](ARCHITECTURE.md) for the source layout and dependency conventions.
